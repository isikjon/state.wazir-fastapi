ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ
Приложение "Недвижимость Wazir"

Дата последнего обновления: 22 июля 2025 г.

1. ОБЩИЕ ПОЛОЖЕНИЯ

Настоящая Политика конфиденциальности регулирует порядок обработки персональных данных пользователей мобильного приложения "Недвижимость Wazir" (далее — "Приложение").

Оператор: MTT Wazir
Контактная информация: info@wazir.kg
Сайт: https://wazir.kg

2. КАКИЕ ДАННЫЕ МЫ СОБИРАЕМ

2.1. Регистрационные данные:
- Номер телефона
- Адрес электронной почты
- Полное имя
- Аватар пользователя (по желанию)

2.2. Данные для компаний:
- Название компании
- Номер юридического лица (ИНН/ОГРН)
- ФИО руководителя
- Логотип компании
- Описание компании
- Адрес компании

2.3. Геолокационные данные:
- Текущее местоположение (с вашего согласия)
- Местоположение объектов недвижимости
- Адреса для поиска

2.4. Контент пользователей:
- Фотографии объектов недвижимости
- 360° панорамы
- Описания объявлений
- Сообщения в чатах
- Отзывы и комментарии

2.5. Технические данные:
- IP-адрес
- Информация об устройстве
- Версия операционной системы
- Модель устройства
- Идентификаторы устройства
- Данные о использовании приложения

2.6. Данные из внешних сервисов:
- Telegram ID (при авторизации через Telegram)
- Контакты (с вашего согласия)

3. ЦЕЛИ ОБРАБОТКИ ДАННЫХ

3.1. Предоставление основных услуг:
- Регистрация и авторизация
- Размещение объявлений
- Поиск недвижимости
- Обеспечение связи между пользователями

3.2. Улучшение сервиса:
- Персонализация контента
- Аналитика использования
- Техническая поддержка
- Предотвращение мошенничества

3.3. Маркетинг и коммуникации:
- Отправка уведомлений о новых объявлениях
- Информирование об обновлениях
- Маркетинговые сообщения (с вашего согласия)

4. ПРАВОВЫЕ ОСНОВАНИЯ

4.1. Обработка осуществляется на основании:
- Вашего согласия
- Необходимости исполнения договора
- Соблюдения правовых обязательств
- Защиты жизненно важных интересов
- Исполнения задач в общественных интересах
- Наших законных интересов

5. РАЗРЕШЕНИЯ ПРИЛОЖЕНИЯ

5.1. Камера:
- Фотографирование объектов недвижимости
- Съемка 360° панорам
- Создание аватара пользователя

5.2. Галерея/Хранилище:
- Загрузка фотографий недвижимости
- Загрузка 360° панорам
- Сохранение избранных объявлений

5.3. Геолокация:
- Определение ближайших объектов
- Построение маршрутов
- Автозаполнение адресов

5.4. Уведомления:
- Push-уведомления о новых сообщениях
- Уведомления о новых объявлениях
- Системные уведомления

5.5. Телефон:
- SMS-верификация номера
- Осуществление звонков продавцам

5.6. Контакты:
- Импорт контактов (по желанию)
- Приглашение друзей

6. ПЕРЕДАЧА ДАННЫХ ТРЕТЬИМ ЛИЦАМ

6.1. Мы можем передавать данные:
- Другим пользователям приложения (в рамках функционала)
- Сервисным провайдерам (SMS, push-уведомления)
- Google Analytics (анонимизированные данные)
- Правоохранительным органам (по требованию закона)

6.2. Мы НЕ передаем персональные данные:
- Рекламным сетям
- Брокерам данных
- Третьим лицам для коммерческих целей

7. БЕЗОПАСНОСТЬ ДАННЫХ

7.1. Меры защиты:
- Шифрование данных при передаче (HTTPS)
- Хеширование паролей
- Регулярное резервное копирование
- Ограниченный доступ сотрудников
- Мониторинг безопасности

7.2. Хранение данных:
- Сервера расположены в защищенных дата-центрах
- Регулярные обновления безопасности
- Аудит систем безопасности

8. СРОКИ ХРАНЕНИЯ

8.1. Активные аккаунты:
- Данные хранятся до удаления аккаунта

8.2. Удаленные аккаунты:
- Персональные данные удаляются в течение 30 дней
- Обезличенные данные могут сохраняться для аналитики

8.3. Сообщения в чатах:
- Хранятся до удаления пользователем
- Автоматическое удаление через 5 лет
